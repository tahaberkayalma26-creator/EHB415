# EHB415: 5G Ağlarına Sensing Yeteneği Entegrasyonu (ISAC) Dönem Projesi

Proje: *Integrating Sensing Capabilities into 5G Networks: An ISAC-Oriented Study*.
Açık kaynak 5G mimarisine ISAC (entegre sensing ve haberleşme) fonksiyonlarının nasıl entegre edilebileceğini ve haberleşme performansına etkisini
simülasyonla inceliyoruz. Kullanılan araçlar: **Sionna** (fiziksel katman/kanal), **ns-3 + 5G-LENA** (ağ seviyesi), **OCUDU** (açık kaynak 5G CU/DU).
